## Process

1. **Brief** — the author sends the form.
2. **Sample or scope** — free 1,000-word sample, or a written plan.
3. **Agreement** — two revision rounds; the author remains author and publisher of record.
4. **The work** — Word / Google Docs; Vellum, Atticus, InDesign; Photoshop, Canva, Kindle Create.
5. **Handoff** — edited `.docx`, print PDF, KPF, EPUB, cover PNG/PDF, source files if requested.
6. **Optional launch** — KDP upload and metadata.
