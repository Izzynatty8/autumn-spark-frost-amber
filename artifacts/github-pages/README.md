## GitHub Pages

This repository’s landing file is `index.html`.

1. Open the repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. The live URL will be:

`https://izzynatty8.github.io/Victors-book-services/`
